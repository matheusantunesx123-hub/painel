Snake Workstation v3.0

Aplicativo desktop nativo do Projeto Snake com tema Obsidiana-Esmeralda. Reúne todos os painéis web, centrais Debian, servidores Oracle e automações de IA em uma interface fluida, sem barra de navegador, com telemetria ao vivo e terminal SSH integrado.

Versão 3.0.0 Portátil Windows 10 / 11 (64-bit) 100% Always Free
Baixar Snake_Workstation_Portable.zip (~235 MB) Baixar Script Instalador (.ps1) ← Voltar para a Área de Comando

Como Instalar e Rodar em Outros Computadores

O pacote portátil do Snake Workstation já inclui todas as bibliotecas necessárias do Chromium (QtWebEngine) e Python embutido. Nenhum software ou dependência precisa ser instalado previamente no outro PC!

OPÇÃO 1 · RECOMENDADA

Baixar e Extrair Zip

Baixe o arquivo Snake_Workstation_Portable.zip, extraia para qualquer pasta (ex: Documentos ou C:\) e execute Instalar_Atalhos.bat para criar os ícones.

OPÇÃO 2 · INSTALADOR 1-CLIQUE

Via Script PowerShell

Abra o PowerShell no outro computador e execute o comando abaixo para baixar, extrair e criar os atalhos automaticamente na Área de Trabalho e Menu Iniciar.

# Comando para instalar automaticamente em outro PC Windows:
irm "http://100.112.218.88:8088/downloads/install.ps1" | iex
